## About the build

Station 562 Badge is my ongoing ESP32 hardware and firmware project. It combines
the physical badge, production firmware, owner documentation, safe self-flashing
tools, and a signed six-stage hardware CTF.

## Public releases

The public repository holds owner-facing releases for CodeCell and Seeed Studio
XIAO builds, along with the documentation needed to use, update, troubleshoot,
and repurpose the hardware safely.
